## 💡 PUNTOS CLAVE A RECORDAR

### Seguridad
```
1. NUNCA hardcodees credenciales en main.py
2. Siempre usa .env (ya está en .gitignore)
3. Credenciales se cargan automáticamente
4. refresh_token es para renovar access_token
```

### OAuth 2.0
```
1. Primera vez: Manual (usuario autoriza)
2. Posteriores: Automático (tokens en .env)
3. Tokens expiran: 24h (access), 365d (refresh)
4. Renovación: Automática si expira access_token
```

### Modo Simulado vs. Real
```
Desarrollo: USE_EXTERNAL_APIS=False (sin APIs)
Producción: USE_EXTERNAL_APIS=True (con APIs)
Tests: Siempre simulado
```

### Plataformas
```
YouTube:  publish_video()      (existente)
TikTok:   publish_video()      (OAuth 2.0)
Facebook: publish_media()      (NUEVO)
Instagram: publish_media()     (NUEVO)
```
